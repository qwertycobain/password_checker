# 🔐 Password Leak Checker

Aplicação web simples que consulta uma API pública de senhas vazadas e verifica se uma senha já apareceu em vazamentos conhecidos.

---

## ⚙️ Stack
- React (Vite)
- API pública de verificação de senhas vazadas

---

## 🔎 Funcionalidades
- Verificação de senha em bases de dados públicas
- Feedback imediato ao usuário
- Interface simples e responsiva

---

## 🚀 Objetivo
Projeto focado em prática de consumo de APIs, segurança básica e desenvolvimento frontend moderno.
